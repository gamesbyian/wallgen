# Automated accessibility testing acceptance

Date: 20 October 2026. Status: **the named browser-automatable accessibility tests have been completed**. This is not native mobile-device, human usability or all-WCAG conformance sign-off.

## Checked gate and evidence standard

The queue asks to **test touch targets, keyboard/focus, colour contrast, screen-reader names, and reduced motion**. We interpret this as a concrete *verification work item*, not as permission to claim that axe-core can listen to TalkBack or that emulated Playwright touch exactly replicates an Android handset. Original source controls, focus paths and theme-dependent computed styles are exercised in production Chromium with deterministic assertions. The separate human/device/AT release boundaries below remain open. The original application and Focus default are unchanged apart from actually justified repairs.

## Limitations and acceptance boundary

- **Native assistive technology remains untested:** no TalkBack or VoiceOver speech output, reading order, rotor/group semantics, actual Android focus announcements or physical keyboard validation. A computed accessible name is not a human hearing an announcement.
- **Physical-device and human ergonomic judgments remain untested:** no real phone taps, pressure/precision, device display rendering, 44px WCAG size exemption adjudication, optical contrast perception with eyesight or human testing of task comprehension. Desktop/mobility/browser emulation are not a native handset.
- **Not exhaustive:** axe automated zero-violation results do not establish all WCAG success criteria, user cognitive accessibility, every multi-setting state or conformance of every unvisited surface. Manual/AT inspection must remain on the release checklist.
- **No design and icon approval:** the eight unwired SVG candidates, all screenshot plates and subjective layout decisions retain their own unchecked review gates.

Thus this is a closure of a **completed automated accessibility test task**, not a claim of complete product accessibility. Negative findings were repaired before closing; nothing was waived, test assertions were never softened, and original feature semantics were preserved.
