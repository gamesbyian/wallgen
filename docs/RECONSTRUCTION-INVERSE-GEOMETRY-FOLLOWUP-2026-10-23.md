## Existing source-backed optics, and the remaining visible gaps

The strongest recent **actual PNG** evidence remains the prior studies, not the three synthetic follow-ups above:

- Independently authored V-shaped seven-hue source: [#615 study](https://github.com/gamesbyian/wallgen/actions/runs/40025249788) improved fitted error **0.192433 → 0.116525**, but source/fit comparison still exposes angular self-intersection, triangular and arrowhead pixels. [#613](https://github.com/gamesbyian/wallgen/pull/613) Chevron preset was worse and closed unmerged.
- Actual current winding Draw: [#630 study](https://github.com/gamesbyian/wallgen/actions/runs/40040643861) improved **0.045805151 → 0.044522707** and the visual stroke is smoother. The upright bend detector in #634 has not yet been source/output evaluated separately.
- Genuine Jagged: **0.165655244** with visible negative-space drift; separately displaced current Jagged case: **0.222146120**. Coupled greedy optimization [#628](https://github.com/gamesbyian/wallgen/pull/628) was rejected unmerged.
- Genuine displaced Rays/Rings: **0.03862013 / 0.06193792** using correct structural family in [#627 study](https://github.com/gamesbyian/wallgen/actions/runs/40037559465); do not call this exact centre, seed, hue order or parameter recovery.
- Holed compound example already reconstructs at **0.0026477658** on the existing real R0 set; this does not prove arbitrary multi-hue overlap or layer order.

The text above distinguishes current-renderer PNG/source-fit viewing from deterministic synthetic Node geometry/recipe proof. No new owner-provided licensed external artwork, Pixel 6 Pro handset images, human acceptance, or full-size 3024×6552 performance test was obtained in this follow-up.

## Next source-first experiments and stopping conditions

1. Reproduce independent angular V corner artifacts at actual PNG scale and inspect **path offset / ribbon union / crossing paint order** against canonical current renderer; modify only the proven seam. Avoid another speculative Chevron family or broad renderer rewrite.
2. Test real Jagged source/result as a negative-space/phase discrepancy using source/renderer-colour masks; record visually reviewed before/after, regress existing Wave/Hairpin/Draw and protect six-plus-ten budget. Do not reinstate #628 without a different measurable discriminator.
3. Add a genuine **14 editable circles** current renderer source, metadata-stripped twin and truth sidecar to optional R0 corpus, plus overlapping/repeated multicolour and nonclassic-palette examples. Optical acceptance is currently **unverified** for #635.
4. Measure real rings/rays original versus inferred parameters without claiming source recipe identity; evaluate whether scene representability, rather than limited candidate fit, is the true defect.
5. Reserve real Pixel interaction/accessibility and owner/licensed external image judgements for explicitly provided source art/device access. Keep deterministic transport, source preservation, provenance and undo checks as separate software proof.
