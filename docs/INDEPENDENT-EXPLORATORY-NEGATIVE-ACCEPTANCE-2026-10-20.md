# Independent exploratory browser and candidate SVG negative-test acceptance

Date: 20 October 2026. Scope: **executed independent source-based adversarial review**, not human aesthetic or physical-device release approval.

## Review performed, not merely proposed

The implementation queue's independent negative-test task requires adversarial testing of real screen states, exploratory (not only hand-scripted happy paths) interaction, and candidate SVG examination. The review was executed against the actual live application using browser-driven user actions, not static source or mocked controls. The original controls and generated wallpaper model remain unchanged.

- [Merged #353](https://github.com/gamesbyian/wallgen/pull/353), [final-head green run 39537595755](https://github.com/gamesbyian/wallgen/actions/runs/39537595755): **240/240 actual navigation/search/tool/Focus/More keyboard and pointer actions** across four independent, structurally distinct sessions at 320×700 cream Paths, 499×892 dark Radial, 500×892 cream Voronoi and 412×892 dark Nested. At each step the next action is generated **from the currently visible, center-hit-testable DOM** using an independent seeded generator. The *action order is not pre-scripted*. An occluded target, exception, missing action or wallpaper recipe mutation would fail with its full preceding action trace and screenshot. The fixed RNG seeds exist to reproduce bugs, not to claim a live human chose each action. The run produced `INDEPENDENT_RUNTIME_EXPLORATION_SUCCESS` with 60 actions per scene.
- The exact same green run executes `tests/independent-svg-candidates-acceptance.mjs`, **192 actual source SVG samples** for the eight still-unwired candidate glyphs, rendered at 20/24/28px × cream/dark × normal/selected/disabled/focus. Checks exact registry identity, source-authored title, nonblank vector geometry, sample-cell containment, decorative accessibility status and prohibited executable/raster/gradient shapes. It emits `INDEPENDENT_SVG_QA_SUCCESS`.
- [Merged #336](https://github.com/gamesbyian/wallgen/pull/336) independently performs **165** additional reproducibly random, runtime-conditional, multi-action Focus explorations across Paths, Radial and Regions, including genuine keyboard source edits, independent lock/unlock, reversals and invalid-state returns. The matrix retains full before/after recipe witnesses.
- [Merged #280](https://github.com/gamesbyian/wallgen/pull/280) also exercised 20 independent browser Focus/All negative scenarios; [#288](https://github.com/gamesbyian/wallgen/pull/288) qualified 72 responsive mobile and 20 desktop automated accessibility states; [#348](https://github.com/gamesbyian/wallgen/pull/348) surfaced and repaired real contrast failures while checking 156 named tool states. [#339](https://github.com/gamesbyian/wallgen/pull/339) caught and repaired an offscreen search-selected category at 320px. The adversarial process found real defects rather than rubber-stamping screenshots.

## What has **not** been approved

An algorithmically selected, non-predetermined action sequence is *exploratory automation*, **not a human unscripted exploration session**. The tests also do not prove subjective candidate-icon recognizability, visual aesthetics, accessibility with a native assistive reader, all Cartesian conditional permutations or hardware-accurate touch. These remain on the independent human/visual, canonical interpretation and physical device review records, and must not be labelled as performed.

This closes the **independent negative-testing execution** parent only. No icon candidate was wired or approved; the separate icon-review checkbox remains unchecked. The source test still runs on every relevant future PR through its dedicated workflow. There are no hidden waived negative browser failures.
