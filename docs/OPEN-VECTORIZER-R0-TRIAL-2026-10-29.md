# #557: Pinned Open Vectorizer vs VTracer on five actual ROYGBIV sources

**Experiment plan, 29 October 2026.** This is a one-shot external **reference oracle** contest, not a production dependency, renderer change, editable-recipe promise, or completion gate. Actual measured evidence and disposition belong here only after a real job completes. Existing source-truth/6+10 model-paint limits remain unchanged.

## Reproducible inputs and tools

- Five metadata-free **480 × 1040 current `drawWallpaper`** PNGs generated by the existing `scripts/review-reconstruction.mjs`: `05-hairpin`, `06-loop`, `11-scattered-circles`, `13-holed-shape`, `22-overlapping-reversed-circles`.
- Open Vectorizer source pinned to [`7b9e49a649c62758e1a1abecab9b2c46d752f1e5`](https://github.com/vardirhq/open-vectorizer/commit/7b9e49a649c62758e1a1abecab9b2c46d752f1e5) (MIT), Rust `png2svg-cli` built from its Cargo.lock, `--mode auto --colors 8 --stats`.
- VTracer official `1.0.0-alpha.4` archive hash `2058f611b48ed49497f78883bde47435531e9e17e3a79428432d1528bdb12e2a`, independently pinned in [VTracer oracle study](RECONSTRUCTION-VTRACER-ACTUAL-ORACLE-2026-10-25.md).
- `scripts/benchmark-reconstruction-vtracer.py` supplies identical independently rasterized black-background RGB error / bright foreground IoU and SVG shape/primitive counts. No original recipe sidecar is inspected by either converter.

## What counts as success

1. Source PNG SHA matches identically for both oracles, source files never modified; no external network dependencies in SVG.
2. All five outputs are genuine complete vector results and PNGs, not future generated previews or unverifiable text claims.
3. Compare per-hue ink, topology and actual artwork, **not only aggregate RGB or fewer SVG nodes**; label source-only and synthetic/generated truth honestly.
4. A candidate is relevant to ROYGBIV only if it can become meaningful canonical editable geometry without new renderer dialect, hidden paint-order claims, extra automatic fitting paint budgets or privacy regression.
5. If traces overfragment the Loop or discard black channels, record that as evidence **against** adoption.

**Cost control:** one job with hard timeout, one temporary manually scoped workflow deleted after experiment, small short-retention artifact, no ongoing CI, no hosted Cloudflare Browser Run.
