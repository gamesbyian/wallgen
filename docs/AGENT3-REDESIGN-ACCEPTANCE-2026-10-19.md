## Consolidated Agent 3 CI execution (pending exact merged-head qualification)

The five small, independent Chromium suites from #184 (responsive dock and keyboard), #193 (source-ID migration census), #196 (39 source-applicable tools), #197 (seven Interior hue targets), and #202 (three Material Finish rotations) are still **independently authored** tests and still produce separate JSON/PNG witnesses. Their five redundant workflow entrypoints have been replaced with one `.github/workflows/agent3-mobile-acceptance.yml`: a single runner, Chromium installation and app server, followed by all five suites. Each test runs even when an earlier test returns nonzero; the aggregate still exits nonzero and uploads each available success/failure record. Do not interpret a partial artifact as passing the aggregate suite. This reduces per-PR browser setup costs and concurrent hosted runners without sacrificing any named test.

The substantial 19.8 MP genuine PNG Download gate and direct world-coordinate foreground pixel gate deliberately remain **separate** workflows, because their memory/runtime/failure domains differ from mobile action reachability. Existing screenshot-atlas, mobile browser, headless export and validation workflows are preserved. Historic GHA run URLs are not rewritten. This refactor needs its own new passing merged-head evidence before the consolidated workflow replaces previous PR-specific evidence as a source-qualification authority.
