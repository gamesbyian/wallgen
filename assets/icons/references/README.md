# Approved ROYGBIV icon-system reference

- **[Original approved concept poster](./roygbiv-icon-system-approved.png)**: the exact 1448×1086 PNG produced and approved in the commissioning conversation, preserved without modification (1,422,201 bytes).
- [Editable vector companion](./roygbiv-icon-system-approved.svg): a fully self-contained reinterpretation of the same layout and aesthetic using SVG icon geometry. This companion is not intended to be pixel-identical with the raster artwork.

The concept poster remains the primary visual design source of truth. The hand-authored SVGs in `../roygbiv/` are the implementation-ready translations of the concept. Both asset groups are staged independently of the live application; no UI integration is performed in this change.
